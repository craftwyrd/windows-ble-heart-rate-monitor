## PulseDesk 首个基础版本

Windows x64 桌面实时心率悬浮窗，通过标准 BLE 心率服务连接手表、手环、胸带等设备。

- 实时心率、最近 60 秒曲线、均值和最高值。
- 红心胶囊、带曲线胶囊、透明 HUD、完整面板四种视图。
- 拖动、置顶、透明度调节，以及托盘显示/隐藏、断开和退出。
- 信号中断提示和最后心率值保留。
- 无设备演示模式：`PulseDesk.exe --demo`。
- 默认中文 README，附英文版说明。

### 下载与使用

下载 **PulseDesk.exe** 后直接运行，无需安装 Python。开启设备的 BLE 心率广播，点击“扫描设备”，选择设备后点击“连接所选设备”。

**SHA256SUMS.txt** 提供 EXE 的 SHA-256 校验值，可用 PowerShell 的 `Get-FileHash .\PulseDesk.exe -Algorithm SHA256` 核对。

### 验证与已知范围

发布流水线在 Windows x64 / Python 3.10.11 上执行解析及 UI 测试、PyInstaller 打包、EXE 演示启动检查和校验文件生成。启动检查只确认进程持续运行，不能代替完整交互测试。真实设备的扫描、连接、持续通知接收尚未在流水线中验证。

设备须提供标准 BLE Heart Rate Service（`0x180D`）及可订阅的 Heart Rate Measurement（`0x2A37`）。不支持 ANT+，不读取 Garmin Connect 账户或历史数据。EXE 未进行代码签名。

## First basic release

PulseDesk is a Windows x64 live heart-rate overlay for devices providing the standard BLE heart-rate service.

- Live bpm, a 60-second chart, average, and peak.
- Four views: heart pill, pill with chart, transparent HUD, and full panel.
- Dragging, always-on-top, opacity controls, and system tray operations.
- Stale-data indication with the last reading retained.
- Device-free preview: `PulseDesk.exe --demo`.
- Chinese documentation by default, with an English README.

Download **PulseDesk.exe** and run it directly; Python is not required. Enable BLE heart-rate broadcasting on your device, then scan and connect. **SHA256SUMS.txt** contains the executable's SHA-256 checksum.

The release workflow runs parsing and UI tests, packages the EXE, checks that its demo process stays running, and generates a checksum on Windows x64 with Python 3.10.11. The startup check does not verify full interaction. Physical BLE scanning, connections, and sustained notifications have not been validated in CI. Standard services `0x180D` / `0x2A37` are required; ANT+ and Garmin Connect history are not supported. The EXE is not code-signed.
